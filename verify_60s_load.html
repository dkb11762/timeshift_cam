STEP21-A 実機負荷検証

このページは検証専用です。本体アプリ(index.html)・4エンジン(bufferEngine.js / playbackEngine.js / storageEngine.js / coordinateEngine.js)・sw.js・manifest.jsonは一切変更していません。 ここでは bufferEngine.js と storageEngine.js を本体と同じファイルとして読み込み、 本番と同じ公開APIだけを呼び出します（StorageEngine.saveShot / loadShotFrames / listShots / deleteShot 以外の 書き込みは行いません。保存レコードへの識別タグ付けのみ、このページから直接IndexedDBへ追記します）。

重要：このページで表示する「ストレージ使用量」は navigator.storage.estimate() による ディスク使用量の推定値であり、RAM（メモリ）使用量ではありません。 iPad Safariからは正確なRAM使用量を取得できないため、RAMの状態は「映像が止まらないか」 「エラーが出ないか」「タブが落ちないか」といった観測可能な指標で判断してください。
